# Chatbot

Primeras pruebas para un chatbot con IA: un contenedor de Docker para probar un modelo de DeepSeek y la planificación del proyecto.

- `chatbot.md`: hoja de ruta con los fundamentos (API en Python, bases SQL y vectoriales para RAG, integración con la web).
- `docker-compose.yml` y `Dockerfile`: el entorno de prueba.
